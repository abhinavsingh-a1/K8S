Why Ingress / what problem service & deployment not able to solve?

A. With deployment only round robin traffic forwarding is possible. While there are enterprise level capabilities for load balancing exist like -

1. Ratio based
2. Sticky session
3. Path based
4. Domain based
5. White listing
6. Black listing
7. TSL
8. WAF
etc.....

B. With loadBalancer, every time static IP was needed. Cloud provider charge per static IP. If there are 1000 static IP, cloud provider will charge for all static IP.

SOLUTION -

KUBERNETES team ask all load balancer companies (ngnix, F5, Ambassedor, traffic, HA Proxy etc.) to write their own INGRESS CONTROLLER and provide process to install INGRESS CONTROLLER using HELM CHART.

As a user, we have to do 2 things -

1. Create INGRESS RESOURCES.
2. Install INGRESS CONTROLLER provided by companies on GITHUB.
